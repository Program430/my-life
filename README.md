# AI Personal Assistant

## Мотивация

Личная информация обычно разбросана между заметками, календарём,
мессенджерами и отдельными приложениями. Из-за этого её неудобно
сохранять, искать и актуализировать.

Этот проект создаёт единый Telegram-интерфейс для управления личными
данными с помощью естественного языка. Пользователь просто пишет, что
нужно сохранить или найти, а ИИ определяет тип информации и выполняет
необходимое действие.

Проект создаётся прежде всего для личного(семейного) использования и постепенно
может расширяться новыми типами данных и сценариями.

## Возможности

Сейчас система поддерживает:

1. Заметки и идеи
2. Календарные события
3. Информацию о долгах
4. Поиск, изменение и удаление сохранённых данных
5. Напоминания о ближайших событиях


## Описание процесса внедрения

### Инструкция по развертыванию самостоятельно(полностью бесплатный вариант актуальный на 08.10.2026):

- GitHub — хранение исходного кода и CI/CD
- Supabase — PostgreSQL и хранение данных
- Render — запуск FastAPI-приложения
- Telegram — взаимодействие с пользователем
- Cloudflare R2 — S3-совместимое хранение резервных копий
- Gemini или Groq — обработка естественного языка

### 1. Создание проекта Supabase

1. Зарегистрироваться на [supabase.com](https://supabase.com).
2. Создать новый проект.
3. Выполнить SQL-скрипт создания таблиц.
4. Скопировать параметры подключения к базе данных.
5. Добавить их в переменные окружения приложения.

Supabase Free предоставляет ограниченный объём базы данных, которого достаточно
для личного MVP.

### 2. Создание Telegram-бота

1. Открыть Telegram и найти `@BotFather`.
2. Выполнить команду `/newbot`.
3. Задать имя и username бота.
4. Сохранить полученный токен.
5. Не публиковать токен в GitHub и README.

### 3. Создание AI-ключа

Получить API-ключ выбранного провайдера Gemini или Groq
и добавить его в переменные окружения.

### 4. Развёртывание на Render

1. Создать аккаунт на [render.com](https://render.com).
2. Подключить GitHub-репозиторий.
3. Создать новый `Web Service`.
4. Выбрать Docker-развёртывание.
5. Добавить переменные окружения.
6. Указать health check:

   `/health`

7. Запустить деплой.
8. Скопировать адрес приложения Render.

Бесплатный Web Service может засыпать после периода бездействия,
поэтому первый запрос после паузы может выполняться дольше. (Можно пинговать переодически чтобы обойти)

### 5. Подключение Telegram Webhook

После успешного деплоя зарегистрировать webhook:

https://api.telegram.org/bot<TELEGRAM_BOT_TOKEN>/setWebhook?url=https://<RENDER_APP_URL>/webhook/telegram

Проверить, что Telegram отправляет сообщения на endpoint приложения.

### 6. Настройка резервного копирования

1. Создать bucket в Cloudflare R2.
2. Создать S3 API-токен с правами на запись объектов.
3. Добавить настройки R2 в GitHub Secrets.
4. Настроить GitHub Actions Workflow.
5. Workflow должен:
   - выполнить pg_dump;
   - сжать резервную копию;
   - загрузить файл в R2;
   - удалить старые копии при необходимости.

### 7. Проверка

После развёртывания проверить:
- GET /health;
- открытие Swagger;
- подключение к Supabase;
- регистрацию пользователя через Telegram;
- создание заметки;
- создание события;
- работу Function Calling;
- загрузку резервной копии в R2.

### Добавление пользователя

1. Администратор открывает админку.
2. Создаёт приглашение для нового пользователя.
3. Система генерирует одноразовый пригласительный ключ
   и ссылку вида:

   `https://t.me/bot_name?start=INVITE_KEY`

4. Администратор отправляет эту ссылку пользователю.
5. Пользователь открывает ссылку и нажимает `Start`.
6. Telegram отправляет боту команду:

   `/start INVITE_KEY`

7. Бэкенд:
   - получает `telegram_id` пользователя;
   - проверяет пригласительный ключ;
   - создаёт пользователя в базе;
   - связывает его с Telegram;
   - помечает ключ использованным.

8. Бот отправляет приветственное сообщение и объясняет,
   какие команды и действия доступны пользователю.

После активации пользователь может обращаться к боту
обычным естественным языком:

- «Запиши идею о…»
- «Кому я должен денег?»
- «Какие события у меня на этой неделе?»
- «Удали заметку про…»
